# Ferixdi AI — Telegram-бот с 14 мифами о Reels

Базовая воронка: /start → 14 мифов → кейсы → информация об обучении → финальное видео без сжатия → кнопка на сайт.
Каждый шаг открывается одной кнопкой. Для начала бот не собирает личные данные и не требует базы данных.

## Запуск на Render Free

1. Открой https://dashboard.render.com/ и выбери **New → Blueprint**.
2. Подключи GitHub и выбери репозиторий **ferixdi-png/telegram**.
3. Render прочитает `render.yaml`. Выбери Free, если доступен.
4. Добавь в Render секрет **BOT_TOKEN** из BotFather (никогда не в GitHub).
5. Публичный адрес бот определяет автоматически по переменной Render `RENDER_EXTERNAL_HOSTNAME`. Вручную его вводить не нужно.
6. **WEBHOOK_SECRET** Render сгенерирует автоматически. Если создаёшь Web Service вручную, задай собственную случайную строку букв/цифр длиной от 32 символов.
7. Сделай Deploy/Redeploy и открой адрес сервиса. Должен ответить JSON `{"status":"ok","bot":"Ferixdi AI Reels"}`.
8. Открой своего бота в Telegram и введи `/start`.

Если Render запустился до ввода адреса или токена, добавь переменные в Environment и выбери Manual Deploy → Deploy latest commit.

## Где менять тексты

Все тексты, порядок кнопок и URL находятся в `content.py`.
Бот не хранит токен в коде. Бесплатный Render может засыпать после 15 минут без обращений, поэтому первый ответ иногда задерживается. Статистика пока только в технических логах, без постоянной аналитики.

## Финальное видео в оригинальном качестве

MP4 хранится в Telegram. На Render достаточно `VIDEO_FILE_ID`. Финальная кнопка отправляет документ через `send_document` по Telegram file_id, сохраняя качество исходника.

1. Открой бота в Telegram и отправь `1007(9).mp4` **как файл (Document)**, размер около 43 МБ. Бот сразу ответит значением `VIDEO_FILE_ID`.
2. Перейди в Render → Environment и создай переменную `VIDEO_FILE_ID` с полученным значением.
3. Сохрани с перезапуском и дождись статуса Live.
4. Напиши боту `/status`. Он покажет версию **v2.2** и состояние привязки видео.
5. Через `/start` можно проверить воронку: 14 мифов → кейсы → обучение → видео → сайт.
6. Команда `/fileid` тоже работает: можно ответить ей на документ либо вызвать после загрузки MP4 в чат.

После обновления сервиса отправь MP4 заново, если он был загружен до внедрения автоматического обработчика.

## Тексты воронки

Контент и подписи кнопок находятся в `content.py`. В пользовательских сообщениях отдельная частица «не» исключена ради разговорного авторского стиля.
