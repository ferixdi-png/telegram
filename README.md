# Ferixdi AI — 16 мифов о Reels за 10 разборов

Базовая воронка: /start → 5 примеров Reels (ещё 6 по желанию) → 10 тематических разборов всех 16 мифов → реальные кейсы → исходный MP4 → сайт и компактное меню.
Каждый разбор открывается одной кнопкой; дополнительные фото и ответы на возражения доступны по желанию. Для начала бот не собирает личные данные и не требует базы данных.

## Запуск на Render Free

1. Открой https://dashboard.render.com/ и выбери **New → Blueprint**.
2. Подключи GitHub и выбери репозиторий **ferixdi-png/telegram**.
3. Render прочитает `render.yaml`. Выбери Free, если доступен.
4. Добавь в Render секрет **BOT_TOKEN** из BotFather (никогда не в GitHub).
5. Публичный адрес бот определяет автоматически по переменной Render `RENDER_EXTERNAL_HOSTNAME`. Вручную его вводить не нужно.
6. **WEBHOOK_SECRET** Render сгенерирует автоматически. Если создаёшь Web Service вручную, задай собственную случайную строку букв/цифр длиной от 32 символов.
7. Сделай Deploy/Redeploy и открой адрес сервиса. Должен ответить JSON `{"status":"ok","bot":"Ferixdi AI Reels"}`.
8. Открой ссылку `https://ferixdi-telegram.onrender.com/start`. Telegram откроет бота с кнопкой **Start / Запустить**; ручной ввод `/start` не требуется.

Если Render запустился до ввода адреса или токена, добавь переменные в Environment и выбери Manual Deploy → Deploy latest commit.

## Ссылка на запуск бота

**Основная:** https://ferixdi-telegram.onrender.com/start

На этом пути Render узнаёт публичный @username своего Telegram-бота через Bot API и перенаправляет на `https://t.me/<username>?start=ferixdi`. Так ссылка продолжит вести на правильного бота даже при изменении его username.

Техническое ограничение Telegram: ссылка с `?start=` открывает чат с кнопкой **Запустить / Start**, которую пользователь нажимает сам (особенно при первом запуске). После нажатия Telegram автоматически отправляет `/start ferixdi`; вручную писать команду человеку не требуется. Бот реагирует обычным стартовым приветствием.

Ссылка заработает после деплоя версии v3.7. Проверить готовность можно командой `/status` (`Ferixdi Bot v3.7`) и открытием маршрута в браузере. Render Free может просыпаться несколько десятков секунд.

**Ещё удобнее для рассылок:** после запуска v3.7 отправь своему боту `/link`. Он ответит настоящей короткой ссылкой `https://t.me/<его_username>?start=ferixdi`. Для Threads, Instagram и Telegram используй именно эту прямую ссылку — она ведёт в бот без промежуточного перехода через Render.

## Где менять тексты

Все тексты, порядок кнопок и URL находятся в `content.py`.
Бот не хранит токен в коде. Бесплатный Render может засыпать после 15 минут без обращений, поэтому первый ответ иногда задерживается. Статистика пока только в технических логах, без постоянной аналитики.

## Контент воронки

Последовательность: `/start` → первые пять визуальных примеров (остальные шесть по кнопке) → 10 тематических разборов 16 мифов → цифры собственных аккаунтов и учеников → исходный MP4 → сайт или необязательное меню.

Тексты и кнопки редактируются в `content.py`. Для читаемости применено HTML-форматирование Telegram: жирный заголовок, номер разбора `01/10`, короткие абзацы, одна кнопка. Содержимое полей `myth` и `answer` экранируется при отправке.

Стиль автора: тёплая живая беседа с подписчиком, от первого лица. Важны не продающие лозунги, а личные ошибки, наблюдения и проверяемые действия. Харизма, дружеские шутки, иногда короткое эмоциональное слово капсом. В блоке о монетизации подчёркнуто: охваты это люди, переходы и возможные заявки, а не только красивый счётчик. В пользовательских сообщениях и кнопках исключены длинные тире, шаблонные маркетинговые фразы и отдельно стоящая частица «не». Прямое приглашение на обучение появляется лишь в добровольной ветке после просмотра видео. Цена и промокод остаются на сайте; прямой разговор о программе начинается только по выбору человека. В других ветках — поддержка уже обучающихся, спокойный ответ на вопрос о бюджете и вариант отложить решение. 

## Подборка Reels сразу после приветствия

Перед первым мифом показывается галерея из 11 скриншотов. Это результаты как аккаунтов автора, так и ребят, которые делают Reels по его системе. Скриншоты содержат **лайки, а не количество просмотров**. Бот сортирует конкретную текущую подборку по убыванию лайков: 136 000, 109 000, 79 000, 71 800, 53 400, 46 400, 36 600, 28 700, 24 600, 23 300, 18 100. Первые пять показываются сразу, остальные шесть только по кнопке. Файловые Telegram ID в публичном репозитории отсутствуют, совпадение выполняется по короткому отпечатку.

Для галереи используй свои 11 скриншотов с результатами. Бот теперь принимает PNG/JPG и как обычные фотографии, и как файлы-документы.

1. Дождись **Live** после обновления GitHub. Проверка `/status` должна показать `Ferixdi Bot v3.7`.
2. В Telegram отправь `/galleryclear`.
3. Заново отправь боту свои **11 скриншотов**. Можно как обычные фото, можно как PNG/JPG-файлы — бот сам подготовит изображения для галереи. Если отправляешь альбомом, Telegram ограничивает его десятью элементами: 10 + 1.
4. Дождись «Все 11 скриншотов на месте!» и отправь `/galleryids`. Подготовка PNG-документов может занять около минуты. Готовую строку из 11 Telegram `file_id` бот пришлёт отдельным сообщением.
5. В **Render → Environment** задай `EXAMPLE_PHOTO_IDS` равным всей строке `file_id` через запятую, без кавычек и пробелов. Сохрани настройки и дождись **Live**.
6. Проверь `/status`: там будет `Примеры: 11 фото`. Затем `/start` → `🔥 А какие ролики залетали?` → пять самых залайканных скринов → `🏁 Давай к мифам` или `📸 Ещё 6 скринов`.

Скриншоты, отправленные до v3.2 в качестве файлов, были отклонены старым обработчиком, поэтому их нужно отправить повторно. Команда `/galleryids` теперь преобразует PNG/JPG-документы в фототип Telegram и пытается убрать временные копии из чата после получения новых `file_id`. При повторной отправке одинаковых файлов бот отсеивает дубликаты по `file_unique_id`.

Для следующей подборки с другими скриншотами можно дополнительно указать `EXAMPLE_PHOTO_LIKES` через запятую, строго в том же порядке, что и `EXAMPLE_PHOTO_IDS`. Тогда бот отсортирует новый набор по этим значениям. Если значения отсутствуют, известная текущая подборка распознаётся и сортируется автоматически.

Если переменная не установлена, бот сразу направит пользователя к мифам. Если Telegram временно откажет в отправке изображений, бот продолжит путь с текстом. Чтобы заменить подборку, повтори процедуру с новыми изображениями.

## Новые мифы и финальные сценарии

Воронка охватывает все 16 мифов за 10 тематических разборов. Три последних разбора посвящены монетизации внимания: Syntx, партнёрства AI и недвижимости, собственное обучение.

- Миф о бесполезности просмотров: автор сообщает о более чем 190 партнёрах Syntx, привлечённых по его ссылке. Это число привлечённых партнёров, а не количество оплаченных заказов или заработанная сумма.
- Миф «AI продаёт только AI»: AI-сервисы — одна партнёрская связка, недвижимость — другая. Трафик на недвижимость пока тестируется, цикл сделки длинный и гарантии комиссий отсутствуют.
- Миф об «инфоцыганстве»: ценность образовательного продукта определяется реальной практикой, доказуемыми результатами и пользой, а не способом монетизации.

После выдачи MP4 пользователь получает две кнопки: прямой переход на сайт с кейсами или «Посмотрел. Что дальше?». Отдельная промежуточная карточка перед MP4 убрана: видео отправляется сразу по кнопке после кейсов.

Последняя кнопка раскрывает основной выбор: «Хочу разобраться глубже», «Я и так умею», «Есть сомнения», «Я уже в группе» и ссылку на кейсы. Креатор с опытом может сразу написать автору по поводу партнёрского трафика.

Ветка «Есть сомнения» открывает по запросу «Всё слишком сложно?», «Пока дороговато», «AI-рынок перегрет?», «С нуля уже поздно?» и «Вернусь позже». В первом случае бот объясняет готовую пошаговую систему: от идеи и инструментов до контента, аналитики и партнёрок. Отдельный сценарий «Я и так умею» предлагает показать переходы по ссылке в Instagram за 30 дней и обсудить трафик с автором в личных сообщениях. Сохраняются личный контакт [@ferixdiii](https://t.me/ferixdiii), информация о программе и кнопка возврата к вопросам.

Для быстрого прохождения 16 мифов объединены в 10 тематических карточек с прогрессом 01/10–10/10. Похожие вопросы идут вместе; реальные кейсы и видео — отдельными шагами.

Подтверждение фактического просмотра видео или сайта бот не проводит: кнопки отражают добровольный выбор пользователя.

## Оригинальное видео без потери качества

Основной путь — `VIDEO_FILE_ID` через Telegram. Если этот идентификатор добавлен в **Render → Environment**, бот повторно отправляет исходный MP4 как файл (Document) без перекодирования.

1. Отправь MP4 боту именно как файл. Он выдаст `VIDEO_FILE_ID`.
2. Добавь `VIDEO_FILE_ID` в Render → Environment, сохрани и дождись Live.
3. Проверь `/status`, затем пройди воронку до последнего шага, затем открой дополнительные варианты после видео.

Резервный путь — GitHub Releases. Если `VIDEO_FILE_ID` отсутствует, бот попытается скачать оригинал отсюда:

`https://github.com/ferixdi-png/telegram/releases/download/video-v1/ferixdi-process.mp4`

Чтобы использовать резервный вариант, создай публичный релиз `video-v1` и прикрепи файл `ferixdi-process.mp4`. Оригинал около 43 МБ, поэтому через стандартный веб-интерфейс загрузки файлов в репозиторий размещать его неудобно.

### Команды

- `/start` — открыть 10 разборов 16 мифов
- `/status` — версия бота и источник MP4
- `/link` — получить прямую Telegram-ссылку с запуском (`?start=ferixdi`)
- `/fileid` — получить идентификатор прикреплённого документа
- `/galleryclear` — очистить временный список фотографий
- `/galleryids` — получить список ID скриншотов для настройки галереи
