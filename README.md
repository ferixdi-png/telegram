# Ferixdi AI — Telegram-бот с 16 мифами о Reels

Базовая воронка: /start → 5 примеров Reels (ещё 7 по желанию) → 16 коротких мифов → кейсы → исходный MP4 → сайт и компактное меню.
Каждый миф открывается одной кнопкой; дополнительные фото и ответы на возражения доступны по желанию. Для начала бот не собирает личные данные и не требует базы данных.

## Запуск на Render Free

1. Открой https://dashboard.render.com/ и выбери **New → Blueprint**.
2. Подключи GitHub и выбери репозиторий **ferixdi-png/telegram**.
3. Render прочитает `render.yaml`. Выбери Free, если доступен.
4. Добавь в Render секрет **BOT_TOKEN** из BotFather (никогда не в GitHub).
5. Публичный адрес бот определяет автоматически по переменной Render `RENDER_EXTERNAL_HOSTNAME`. Вручную его вводить не нужно.
6. **WEBHOOK_SECRET** Render сгенерирует автоматически. Если создаёшь Web Service вручную, задай собственную случайную строку букв/цифр длиной от 32 символов.
7. Сделай Deploy/Redeploy и открой адрес сервиса. Должен ответить JSON `{"status":"ok","bot":"Ferixdi AI Reels"}`.
8. Открой своего бота в Telegram и введи `/start`.

Если Render запустился до ввода адреса или токена, добавь переменные в Environment и выбери Manual Deploy → Deploy latest commit.

## Где менять тексты

Все тексты, порядок кнопок и URL находятся в `content.py`.
Бот не хранит токен в коде. Бесплатный Render может засыпать после 15 минут без обращений, поэтому первый ответ иногда задерживается. Статистика пока только в технических логах, без постоянной аналитики.

## Контент воронки

Последовательность: `/start` → первые пять визуальных примеров (оставшиеся шесть — по кнопке) → 16 коротких историй → кейсы → видео → сайт или необязательное меню.

Тексты и кнопки редактируются в `content.py`. Для читаемости применено HTML-форматирование Telegram: жирный заголовок, номер мифа `01/16`, короткие абзацы, одна кнопка. Содержимое полей `myth` и `answer` экранируется при отправке.

Стиль автора: от первого лица, реальные наблюдения, разговорный тон и конкретные цифры. Прямое приглашение на обучение появляется лишь в добровольной ветке после просмотра видео. Цена и промокод в бот не встроены: актуальные условия находятся на сайте. В других ветках — поддержка уже обучающихся, спокойный ответ на вопрос о бюджете и вариант отложить решение. В пользовательских текстах исключена отдельно стоящая частица «не».

## Подборка Reels сразу после приветствия

Чтобы зритель увидел примеры до первого мифа, предусмотрена галерея до двенадцати скриншотов: первые пять показываются сразу, остальные семь — только по запросу. Это **снимки роликов с видимыми лайками**, а не файлы самих Reels. Тексты не приписывают все ролики владельцу бота и не выдают лайки за просмотры.

Для галереи используй свои 12 скриншотов с охватами. Предыдущий архив содержит только 11 изображений, так что нужен ещё один снимок из твоей подборки.

1. Дождись нового статуса **Live** после деплоя.
2. Открой Telegram-бота и отправь `/galleryclear`.
3. Отправь свои 12 скриншотов боту **как фото**. Максимум 10 в одном альбоме: сначала 10, потом ещё 2. Фото документами пока не принимаются.
4. Когда бот напишет «Все 12 скриншотов получил», отправь `/galleryids`. Он вернёт одну строку из 12 Telegram file_id. Если фото ещё идут, дождись последнего.
5. В **Render → Environment** добавь одну переменную: ключ `EXAMPLE_PHOTO_IDS`, значение — все 12 file_id через запятую без пробелов и кавычек. Они хранятся в настройках Render, а не в GitHub.
6. Сохрани, дождись **Live**, проверь `/status`: `Примеры: 12 фото`.
7. Пройди `/start` → `🔥 Покажи, что залетало` → первый альбом до 5 изображений → `🏁 К первому мифу` или `📸 Ещё 7 примеров`.

Если переменная не установлена, бот сразу направит пользователя к мифам. Если Telegram временно откажет в отправке изображений, бот продолжит путь с текстом. Чтобы заменить подборку, повтори процедуру с новыми изображениями.

## Новые мифы и финальные сценарии

Воронка включает 16 мифов. Финальные три шага посвящены разным способам монетизации.

- Миф о бесполезности просмотров: автор сообщает о более чем 190 партнёрах Syntx, привлечённых по его ссылке. Это число привлечённых партнёров, а не количество оплаченных заказов или заработанная сумма.
- Миф «AI продаёт только AI»: AI-партнёрки и дальнейшее обучение других при наличии своего опыта — одна модель; тестовый трафик на партнёрки недвижимости — дополнительная модель с долгим циклом сделки и потенциально крупными выплатами. Эксперимент описан как тест, без гарантий.

После выдачи MP4 пользователь получает две кнопки: прямой переход на сайт с кейсами или «Видео посмотрел, что дальше?».

Последняя кнопка раскрывает компактный **основной выбор**: «Хочу разобраться глубже», «Есть сомнения», «Я уже в группе», плюс прямая ссылка на кейсы. Человек без возражений сразу идёт к своему варианту.

Ветка «Есть сомнения» раскрывает вопросы только по запросу: «Пока дороговато», «AI-рынок перегрет?», «С нуля уже поздно?», «Вернусь позже». Сохраняются личный контакт [@ferixdiii](https://t.me/ferixdiii), информация о программе и кнопка возврата к вопросам.

Длинные монологи сокращены. Все 16 мифов остаются отдельными короткими карточками для интереса и понятного прогресса 01/16–16/16.

Подтверждение фактического просмотра видео или сайта бот не проводит: кнопки отражают добровольный выбор пользователя.

## Оригинальное видео без потери качества

Основной путь — `VIDEO_FILE_ID` через Telegram. Если этот идентификатор добавлен в **Render → Environment**, бот повторно отправляет исходный MP4 как файл (Document) без перекодирования.

1. Отправь MP4 боту именно как файл. Он выдаст `VIDEO_FILE_ID`.
2. Добавь `VIDEO_FILE_ID` в Render → Environment, сохрани и дождись Live.
3. Проверь `/status`, затем пройди воронку до последнего шага, затем открой дополнительные варианты после видео.

Резервный путь — GitHub Releases. Если `VIDEO_FILE_ID` отсутствует, бот попытается скачать оригинал отсюда:

`https://github.com/ferixdi-png/telegram/releases/download/video-v1/ferixdi-process.mp4`

Чтобы использовать резервный вариант, создай публичный релиз `video-v1` и прикрепи файл `ferixdi-process.mp4`. Оригинал около 43 МБ, поэтому через стандартный веб-интерфейс загрузки файлов в репозиторий размещать его неудобно.

### Команды

- `/start` — начать 16 историй
- `/status` — версия бота и источник MP4
- `/fileid` — получить идентификатор прикреплённого документа
- `/galleryclear` — очистить временный список фотографий
- `/galleryids` — получить список ID скриншотов для настройки галереи
